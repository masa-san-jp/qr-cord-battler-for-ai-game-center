# プレイの流れ（起動 → ゲームオーバー）と戦闘ルール

QR SMASH ARENA。QR から決まる 5 パラメータで、最大 3 ターンの自動対戦。連打なし。

## 起動
- `index.html` をブラウザで開く（`file://` でも可。確実に動かすなら `python3 -m http.server 5000`）。
- 画像生成を使うなら先に `imggen/serve.sh` を起動（任意。無くてもプレースホルダで遊べる）。

## 1. タイトル
- 左右に AI 生成キャラがショーケースで巡回表示。
- `[1] 1P vs CPU` / `[2] 2P 対戦`。`1` か `2`（または画面タップ）で開始。

## 2. 対戦開始（席）
- **1P**：左＝自分（`?p1=` 指定 or ランダム）／右＝CPU（素材からランダム）。
- **2P**：左＝先行（`?p1=`）／右＝後行（`?p2=`）。
- 各キャラを大きく表示（QR は非表示＝秘密のコレクション感）。上に HP バー＋TIER、下に 5 パラメータ。

## 3. QR から決まる 5 パラメータ（合計＝TIER）
| パラメータ | 効果 |
|---|---|
| HP | 体力プール。さらに高いほど回避しやすい |
| 攻撃力 | 通ったダメージが大きい |
| 防御力 | 高いほど相手の攻撃を回避しやすい |
| 素早さ | 高い方が先に攻撃する |
| カウンター率 | 攻撃された時、その確率で反撃（追加ダメージ） |

- **TIER**＝5 パラメータの合計：`SSS=1000 / SS=800 / A=600 / B=500`。
- 「同じ QR 文字列 → 常に同じ戦士」（決定論）。

## 4. 戦闘（自動・最大 3 ターン）
- ターン順：**素早さが高い方が先攻**（同値は先行＝左）。1 ターンで両者が 1 回ずつ攻撃。
- 各攻撃の解決：
  1. **回避判定**：回避率 = clamp((相手HP + 相手防御) / TIER合計 × 55 + 速度差 × 0.05, 5%, 75%)。回避なら MISS。
  2. **命中ダメージ** = 攻撃力 × 0.4 ×（属性相性 1.25 or 1.0）。
  3. **カウンター**：命中時、被弾側がカウンター率の確率で反撃（被弾側 攻撃力 × 0.4 × 相性）。
- 属性相性：火→自然→雷→水→火、光⇔闇 で **効果抜群（1.25 倍）**。

## 5. 決着（ゲームオーバー）
- 3 ターン以内にどちらかの HP が 0 → **K.O.**。
- 3 ターンで決まらなければ **残 HP の多い方が判定勝ち（JUDGE）**。同値は DRAW。

## 6. 勝利画面
- 暗転 → **勝者キャラを中央に大きく** → `K.O.`/`JUDGE` ＋ `YOU WIN!`（or `CPU WIN`/`PLAYER n WIN!`）＋ 名前・属性・TIER。
- `SPACE`（or タップ）でタイトルへ。

## デモ運用メモ
- 数値係数（ダメージ 0.4・回避式・カウンター換算）は `src/game.js` / `src/core.js` で調整可。
- 展示は固定対戦（`?p1=…&p2=…`）＋事前生成肖像が安定（生成待ちゼロ）。`tools/pregen-portraits.js` で焼ける。
- 肖像が無くても属性色プレースホルダで即プレイ可。画像生成が落ちてもゲームは成立。
