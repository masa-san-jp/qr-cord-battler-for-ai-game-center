# プレイの流れ（起動 → ゲームオーバー）

QR SMASH ARENA の、立ち上げから 1 ゲーム終了までの流れ。デモ運用の前提整理用。

## 起動
- `index.html` をブラウザで開く（ビルド不要・`file://` でも可。確実に動かすなら `python3 -m http.server 5000` 経由）。
- 画像生成を使うなら先に `imggen/serve.sh` を起動（任意。無くてもプレースホルダで遊べる）。

## 1. タイトル画面
- 「QR SMASH ARENA」表示。左右に AI 生成のキャラがショーケースで巡回表示（事前生成済みなので即時）。
- メニューを大きく常時表示：`[1] 1P vs CPU` / `[2] 2P 対戦`。
- 入力：`1` か `2`（または画面タップ）で開始。

## 2. 対戦開始
- 選んだファイター 2 体が画面左右に**大きく**表示（QR コードは表示しない＝秘密のコレクション感を保つ）。
- 各キャラの上に HP バー、下に CHARGE ゲージ。中央上に残り時間（60 秒）。
- 固定対戦は URL で指定可：`index.html?p1=ドラゴン&p2=フェニックス`（同じ文字列 → 常に同じキャラ）。

## 3. 戦闘（連打バトル）
- 連打でチャージが溜まる：1P=`F` または `Space` / 2P=`J`（1P 戦は相手が CPU）。画面タップでも連打可。
- チャージ満タンで相手へ攻撃が自動で飛び、相手のキャラに着弾 → ダメージ（被弾フラッシュ＋ダメージ数字＋粒子＋画面シェイク）。
- 3 回チャージごとに **SUPER**（大ダメージ・派手演出）。
- 属性相性（火→自然→雷→水→火 ＋ 光⇔闇）で **効果抜群（1.25 倍）**。
- 連続ヒットで **COMBO** 倍率上昇。

## 4. 決着（ゲームオーバー）
- 相手の HP を 0 に → **K.O.**。または 60 秒で残 HP 割合が多い方の勝ち（同率は DRAW）。
- いずれも 1 分以内〜数十秒で必ず決着（タイマー上限で無限ループしない）。

## 5. 勝利画面
- 暗転 → **勝者のキャラクターを中央に大きく**表示 → `K.O.` / `YOU WIN!`（または `CPU WIN` / `PLAYER n WIN!`）／キャラ名・属性・レア度。
- `SPACE`（または連打キー／タップ）で**タイトルへ戻る**。

## デモ運用メモ（確実に遊べるように）
- 展示は固定対戦＋事前生成肖像が安定（生成待ちゼロ）。`tools/pregen-portraits.js` で焼ける。
- ランダム対戦時：肖像が間に合わなければ属性色のプレースホルダで即プレイ可能、生成が届けば差し替わる。画像生成サービスが落ちていてもゲームは成立。
- 1 プレイは最大 60 秒。説明不要（メニューと連打キーを常時表示）。
