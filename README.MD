# QR SMASH ARENA

QRコードを**連打で破壊し尽くす**アーケード対戦ゲーム。
モバイル版 [`qr-cord-battler`](https://github.com/masa-san-jp/qr-cord-battler) の決定論的キャラ生成ロジックを流用した、ゲームセンター／ハッカソン展示向けの派生作。

```
ブラウザで index.html を開くだけ。ビルド不要・インストール不要。
```

## ハッカソン要件への対応

| 要件 | 対応 |
|---|---|
| 3分で終わる | 1ラウンド ≈ 15〜40秒（タイマー上限60秒）。説明〜決着まで1分以内 |
| 説明不要で遊べる | 操作は**連打のみ**。タイトルに大きく `[1] 1P vs CPU` `[2] 2P対戦`、連打キーを常時表示。画面タップでも可 |
| 後ろから見て楽しい | 破片の飛散・画面シェイク・コンボ数・ダメージ数字・属性カラーのフラッシュ・SUPER演出・KOスローモー |

## 選んだイディオム

- **対戦** … 1P（CPU戦）／2P（人対人）。CPUは相手の SPD に応じた連打速度で挙動。
- **デストラクション** … QRコード＝壊せるブロックの集合。黒モジュール1つ＝HPの実体。叩くたびに目に見えて消えていく（テトリスの「積み上がり＝ペナルティ／消えると爽快」の逆＝「壊して減らす爽快」）。

## 遊び方

| | 連打キー | タッチ |
|---|---|---|
| 1P（左） | `F` または `Space` | 画面左半分タップ |
| 2P（右） | `J` または `Enter` | 画面右半分タップ |

- 連打で **CHARGE** が溜まり、満タンで自動的に相手のQRへ攻撃が飛ぶ。
- 3回チャージごとに **SUPER**（大ダメージ・ビーム演出）。
- 属性相性（火→自然→雷→水→火 の三すくみ＋光⇔闇）で **効果抜群（1.25倍）**。
- 連続ヒットで **COMBO** 倍率上昇。
- 相手のQRを全壊で **K.O.**。60秒で決着しなければ残QR割合が多い方の勝ち。

決着後は `Space` でタイトルへ。

### 決定論

「同じQR文字列 → 常に同じファイター（属性・レア度・ステータス・QR模様）」。
URLパラメータで固定対戦も可能:

```
index.html?p1=おまえの推し文字列&p2=対戦相手の文字列
```

指定しなければ毎回ランダム生成（GACHA）。

## 起動方法

- **最速**: `index.html` をダブルクリック（`file://` で動作）。
- ローカルサーバ経由が良い場合: `npx serve` または `python3 -m http.server` してアクセス。

## 構成

```
index.html     画面シェル（Canvas 1280x720, 自動スケール）
src/core.js    決定論的ファイター生成（mulberry32 RNG・属性相性・QR模様生成）
src/game.js    ゲームループ・状態管理・描画・入力・演出
```

依存ライブラリ・フレームワークなし（Vanilla JS + Canvas）。

## 正直な制約・既知事項（誠実であること）

- **このQRはスキャン可能な本物のQRではない。** 決定論的に「QRらしく見える」模様を生成しているだけ（3隅のファインダーパターン＋ハッシュ由来のモジュール）。実機カメラ連携は含まない。
- **ハッシュは SHA-256 ではなく軽量ハッシュ（FNV系）。** ブラウザ単体・同期実行のための代替で、暗号強度はない。本家モバイル版とはファイター生成結果が一致しない（生成ロジックを vendor したため）。
- **音は未実装。** 展示で映えるならSE/BGM追加が次の一手。
- **バランスは手調整段階。** CPUはやや手強め。`game.js` の `doMash`／`damage`／CPU `cpuTimer` 係数で調整可能。
- **2P対戦は同一キーボード前提**（左右キー分担）。物理ボタン筐体に載せる場合はキーマップ変更が必要。
